# Редизайн trip-control.com — план (14.10.2026)

Свят, це план редизайну за двома новими макетами. Світла тема — `usermenu/a.html` (кремовий фон, темно-бірюзовий акцент), темна — `usermenu/b.html` (navy-фон, periwinkle-акцент). Розмітка в обох однакова. Код я не міняв: тільки читав клон `tc-ro` (коміт d45c415).

## Мета
- Дві нові теми замість `control`/`paper`: **light** (за a.html) і **dark** (за b.html). Graphite/Nordic більше не робимо.
- **Ocean видаляємо повністю** (твоя пряма команда 14.10). Залишаються тільки light і dark, light — дефолт для всіх.
- Редизайн іде **перед** меню користувача. Меню-аватар (розд. 8 старого плану) стає частиною нової шапки.
- Формули, calc API, БД і міграції не змінюються. Міняємо тільки UI/CSS/розмітку.
- Шрифти: Manrope для тексту, JetBrains Mono для цифр і сум.
